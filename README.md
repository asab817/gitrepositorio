# Proyecto de Trabajo con Git

Este proyecto demuestra el uso de Git para gestionar repositorios remotos y locales. Se incluyen los siguientes pasos:

- Creación de un repositorio en GitHub.
- Creación de un repositorio local y vinculación con el remoto.
- Clonación del repositorio.
- Resolución de conflictos.
- Uso de archivos `.gitignore` y `README.md`.
